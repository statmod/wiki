## Задание

Создать программу, с помощью которой можно организовывать соревнования по анализу данных, похожие то, что есть на kaggle.com.

(Мотивация: для участия в соревнованиях на kaggle нужна верификация по номеру телефона, что часто не работает.)

### Баллы

2 курс – 25 баллов, 1 курс – 50 баллов (баллы могут сильно увеличиться при увеличении функциональности программы).

### Подготовка

Необходимо знание подходящего для задачи языка программирования с ООП.

### Требования к программе

Как устроены соревнования на kaggle: Есть набор соревнований, одно соревнование = один набор данных. В каждом соревновании данные (таблица) делятся на три части, для одной части пользователю даются данные вместе с ответами, для второй и третьей части данные без ответов. Можно посмотреть на описательную статистику данных. Пользователь загружает ответы по второй (public) и третьей (private) части (каждая строка таблицы с данными долдна иметь уникальный ID), ему показывается величина ошибки его ответов по второй части, а по третьей части ошибку видит только организатор соревнований. Частота загрузки регулируется, типа сколько-то раз в день, не чаще. Все видят список пользователей, упорядоченный по величине ошибок на второй части, организатор видит список, упорядоченный по результатам на private, и все попытки пользователей. В заданный организатором момент открывается список с ошибками на третьей части, на основе которого, условно, ставятся оценки, присуждается приз, …

Что предполагается в минимальной версии программы. В программе реализовано два типа соревнования, предсказание значений какой-то характеристики (регрессия) и предсказание номера класса (классификация), для каждого из них возможны несколько метрик качества, организовано несколько соревнований (загружены данные, есть индикатор разбиения на три части, выбрана метрика качества). Программа работает в двух режимах - для пользователя и для организатора.

Организатор может добавлять пользователя, может загружать ответы пользователя. Программу можно попросить выгрузить данные (с ответами только по первой части, если для пользователя), можно попросить выгрузить упорядоченный список (на public, если для пользователя). Можно попросить выдать короткое описание данных и описательную статистику.

Обязательное требование: удобное изменение кода (ООП) для добавления соревнования и новой метрики качества.
