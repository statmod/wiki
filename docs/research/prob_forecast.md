title: "Метод наименьших квадратов для временных рядов, поиск лучшей модели (на весну 2024/25 тема занята)"
---

Пусть есть данные в виде \$(x_i, y_i), i=1,\ldots,N\$. Нужно по \$x_i\$ уметь предсказывать \$y_i\$. Задается модель предсказываемой функции - ее параметрический вид, когда параметры неизвестны, но оцениваются по данным. Например, \$\hat{y}\_i = a x_i + b\$ (линейная регрессия), \$\hat{y}\_i = a x_i^2 + b x_i + c\$ (квадратичная регрессия), \$\hat{y}\_i = b\exp(a x_i)\$ (экспоненциальная регрессия). Подходящие под данные модели можно предложить самостоятельно. Это можно сделать, например, посмотрев на графики данных. А можно - используя разные найденные в литературе теоретические модели.

В случае временных рядов в качестве \$x_i\$ выступают моменты времени, например, \$x_i = i\$, где \$i\$ - номер дня, начиная с какой-то фиксированной даты.

Коэффициенты ищутся с помощью метода наименьших квадратов подбором параметров через поиск минимума \$\min\sum\_{i=1}^N (y_i -\hat{y}\_i)^2\$. Для поиска параметров в случаях, которые сводятся к линейной регрессии, есть явные формулы. А в остальных случаях задача решается применением численного метода поиска минимума.

Дополнение 2020: Нужно придумать алгоритм, который определяет число волн в разных географических точках.

Дополнение 2021: Предполагается, что остатки после выделения тренда нужно исследовать на периодичность (проблема сбора данных).


## Задание


Предлагается взять временные данные по коронавирусу отсюда <https://github.com/CSSEGISandData/COVID-19/tree/master/csse_covid_19_data/> и проверить для разных временных отрезков, какая модель лучше подходит на разных временных отрезках и есть ли система в том, как одна лучшая модель сменяется другой с течением времени в разных географических точках.

Если такая система есть, то можно попробовать предсказать следующую модель, если в данный момент лучше подходит та или иная из них, а модели сменяют друг друга в определенном порядке.

Если в моделях одинаковое количество параметров, то сравнивать их можно по ошибке аппроксимации (минимальной сумме \$\min\sum\_{i=1}^N (y_i -\hat{y}\_i)^2\$). Однако, если параметров разное количество, то этот вариант не годится. Есть разные подходы. Но самый простой - сравнение моделей по ошибке прогноза с оцененными по МНК параметрами.
