**ВАЖНО: информация на этой странице устарела. Рекомендуется для оформления дипломной работы использовать пакет [disser](disser.md). Актуальный вариант страницы доступен в [wiki](titlepagenew.md)**

Как известно, титульная страница должна быть оформлена <<по стандарту>>: на ней должны присутствовать вполне конкретные <<элементы>>. Для унификации [^1] был написан специальный стилевой файл, который “подменяет” стандартную команду `\maketitle` и печатает соотв. титульную страницу.

# Использование стилевого файла

Использовать стилевой файл просто:

1.  Загрузить [архив](../assets/latex/titlepage.zip).
2.  Положить файл `statmodtitle.sty` в каталог, где его сможет найти TeX. Например, можно просто положить в каталог с основным .tex‘овским исходником дипломной работы. - Подключить стилевой файл в преамбуле: ’‘\usepackage{statmodtitle}’’
3.  Задать требуемые поля (список полей — ниже).
4.  Дать команду `\maketitle`

# Список полей

1.  `\author` — Автор. В именительном падеже.
2.  `\title` — Тема
3.  `\subtitle` — Подтема (optional)
4.  `\facility` — Кафедра
5.  `\date` — Год защиты
6.  `\reviewer` — Рецензент
7.  `\supervisor` — Научный руководитель
8.  `\chief` — Зав. кафедрой.

В комплекте предлагается <<готовый>> пример титульного листа.

[^1]: Некоторые, не понимая смысла расположения фамилий на тит.листе, меняют его неправильно. Руководитель и рецензент подписывают отзыв и рецензию, соответственно. Их фамилии на титульном листе носят информативный характер. А зав. кафедрой должен подписать каждую работу. Поэтому на титульном листе есть место для подписи, а внизу идет расшифровка подписи.
