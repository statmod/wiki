## Введение

 Пакет disser позволяет автоматизировать множество рутинных операций, связанных с оформлением выпускной квалификационной работы: правильные титульный лист, список литературы, структура работы и т.п.

Презентацию, содержащую список требований, можно взять [отсюда](../assets/latex/diploma-rules3.pdf). Ниже приведены некоторые важные пункты


## Установка


- Disser доступен на CTAN, во многих дистрибутивах (последнем MikTeX) он уже доступен “из коробки”
- TDS архив доступен [тут](http://sourceforge.net/projects/disser/files/disser.tds/1.1.9/disser-1.1.9.tds.zip/download)
- Скачать исходный текст пакета можно [здесь](http://sourceforge.net/projects/disser/files/disser/1.1.9/disser-1.1.9.zip/download)

Для работы пакета disser необходимо наличие следующих пакетов: amsfonts, amsmath, amssymb, caption, cmap, graphicx, ifpdf, natbib, oberdiek, hyperref, hypernat, subfig, wrapfig. Как правило, большая часть из них (кроме oberdiek) ставится по-умолчанию при любой более-менее разумной установке.


### Процедура установки под MikTeX (из TDS архива, на примере MikTeX 2.8)


1.  Создаем каталог для локальных дополнений к TeX’e (например, C:\Doсuments and Settings\\UserName>\localtexmf)
2.  Распаковываем TDS архив в этот каталог. Таким образом, внутри каталога, созданного в п.1, появляются подкаталоги bibtex, doc, source, tex
3.  Запускаем Пуск->Программы->MikTex 2.8->Maitenance (Admin)->Settings (Admin)
4.  Идем на вкладку Roots и добавляем каталог, созданный в п.1, через кнопку Add.
5.  Жмем OK.


### Процедура установки под MikTeX (из исходного текста)

 Необходимо выполнить следующие команды в консоли из каталога, куда был распакован пакет

      set DESTDIR=disk:\path\to\texmf
      nomake install

Здесь `disk:\path\to\texmf` - путь к дереву TeX‘а (обычно - каталог ’‘localtexmf’‘). После этого необходимо произвести процедуру обновления путей. В MiKTeX это делается так: ’‘Start->Programs->MikTex->MikTex options.’’ Там на странице `General` нажать `Refresh now`.


### Процедура установки не-под Windows

 Необходимо выполнить следующую команду из консоли

      env DESTDIR=/path/to/texmf make install                                                            

здесь `/path/to/texmf` - путь к дереву TeX‘а. После этого следует проивести перегенарцию путей поиска при помощи команды ’‘mktexsr’’


## Использование

 Основной шаблон-пример находится в каталоге `template/specialist`. Рекомендуется внимательно его изучить и приспособить под собственные нужды.


## Важные моменты и требования


- Библиография оформляется с использованием стиля gost2008 / gost705
- Для сборки библиографии нужно использовать bibtex8 (примерно так:

<!-- -->

      bibtex8 -H -c cp1251.csf thesis.aux

где thesis.aux - .aux файл для работы (может называться иначе, если файл с текстом - это не thesis.tex)

- Титульный лист оформляется по [правилам](titlepagenew.md)
- Для хранения и оформления списка литературы в формате bibtex удобно использовать так называемые reference managers, например, [JabRef](http://jabref.sourceforge.net).
