## Введение

Это описание сделано для связки MIKTEX 2.4 и WinEdt 5.4 (или 5.3, 5.2). На данный момент (апрель-2010) с сайта [http://www.miktex.org](http://www.miktex.org) можно скачать версию 2.8. Для версий MIKTEX ≥2.5 устанавливать доп.пакеты beamer и пр. не нужно - они там уже правильной версии.

Есть еще много других редакторов кроме WinEdt, в которых можно работать с TEXом. Например, бесплатно распространяемый TeXnicCenter. См. также обсуждение на [форуме](http://statmod.ru/forum/viewtopic.php?p=1224#1224)

## Установка

После установки MIKTEX 2.4 нужно обновить пакеты beamer, xcolor, pgf (есть на CD, но можно загрузить пакеты со страницы [downloads](http://sourceforge.net/project/showfiles.php?group_id=92412)). В директории **localtexmf** есть поддиректория **tex**, а в ней – поддиректория **latex** (если нет, то создайте). Внутри нужно создать еще поддиректории с именами **beamer**, **pgf**, **xcolor** и в них скопировать файлы из пакетов (содержимое папок **latex-beamer-3.07**, **pgf-1.01**, **xcolor** соответственно). Затем вызвать *Start-Programs-MikTex-MikTex options*. Там на странице *General* нажать *Refresh now*.

На всякий случай, напоминаю, как сделать, чтобы были переносы в русском языке: *Start-Programs-MikTex-MikTex options*, страница *languages*, ставите галочку на *russian*, убираете галочку *nohyphenation*. Потом два раза на *OK* (в MIKTEX 2.4 этого достаточно; в MIKTEX 2.1 нужно еще на странице *General* нажать кнопки *Refresh* и/или *Update*).

**ВНИМАНИЕ:** В MikTex 2.9 beamer есть в комплекте поставки. Ничего дополнительно устанавливать не надо

## Возможности и примеры

Слайды, приготовленные с помощью beamer, имеют огромное число возможностей. Примеры (а также руководство по использованию класса beamer) можно посмотреть в директории **tex/latex/beamer/doc**.

Возможностей даже слишком много, поэтому предлагаем два примера на основе презентаций 2006 года с комментариями внутри. Слайды для защиты дипломных работ должны быть простые, так как возможно управлять показом будет посторонний человек (а не вы)

<u>Пример1</u> (zip), стиль наиболее строгий, по умолчанию: [pdf (200K)](../assets/latex/beamer_slides_simple1_pdf.zip), [tex (10K)](../assets/latex/beamer_slides_simple1_tex.zip)

<u>Пример2</u> (zip), стиль Warsaw: [pdf (200K)](../assets/latex/beamer_slides_simple2_pdf.zip), [tex (10K)](../assets/latex/beamer_slides_simple2_tex.zip)

<u>Пример3</u>\_(zip), стиль Frankfurt. Этот, гораздо более сложный, пример “рисования” при помощи встроенного в beamer пакета tikz, вставки и разметки кода программ: [tex+pdf](../assets/latex/syrcose.zip)

Проблема с русификаций bookmarks (закладок) в PDF в beamer решена (опция unicode), только bookmarks имеют другой смысл (презентацию можно иерархически разделить на части, разделы и подразделы). ## Комментарии к темам

Темы beamer’а содержат различные комбинации визуальных элементов. Выбор, какая тема уместна в том или ином случае, очень важен: опасно как “перегрузить” презентацию, так и “недогрузить”. Комментарии будут накапливаться по мере поступления

- **Warsaw**: В первую очередь тема предназначена для длительных презентаций (20-30 мин. и более) с рассчетом на аудиторию, которая может не знать ни темы доклада, ни докладчика. Как правило, это большие конференции, семинары, доклады, invited talks и т.п.
- **Frankfurt**/**Darmstadt**: Облегченный вариант темы **Warsaw**. Длинные презентации, но с расчетом на аудиторию, которая будет знать тему доклада и самого докладчика. Презентации на специализированных секциях конференций и т.п.

## Тема “StatMod”

Для защиты дипломных работ была сделана специальная тема, которая содержит в себе все необходимые элементы. Взять ее можно [здесь](../assets/latex/beamerstatmod.zip). Пример использования [здесь](../assets/latex/beamerstatmodexample.zip) (использование пакета tikz там закомментировано и шрифты, пожалуй, слишком крупные - НЭ).

А [это](../assets/latex/big_example.zip) - пример слайдов с защиты-2007.

### Порядок установки

1.  Убедиться, что beamer поставлен в каталог **localtexmf\tex\latex\beamer**
2.  Убедиться, что в каталоге **localtexmf\tex\latex\beamer** есть подкаталог **themes**
3.  Распаковать архив туда
4.  Выполнить *Refresh Now* так же, как и при установке beamer’а
5.  Убедиться, что “пример” собирается.
6.  Тему подключать как обычно, т.е. посредством:

<!-- -->

    \usetheme{Statmod}

### Поддерживаемые опции

Общий синтаксис вызова:

    \usetheme[opt1, opt2, ...]{Statmod}

Здесь optN - одно из следующих значений

- *compress* - “Сжимать” шапку
- *minimal* - Очень сильно “сжимать” шапку
- *nonav* - Отключить навигационную полосу
- *sand* - Изменить цвет фона с белого на песочный
- *numbers* - Печатать номер слайда
- *totalnumbers* - Печатать общее кол-во слайдов. Использовать только вместе с опцией *numbers*
- *nologo* - Отключить логотип

Во избежание недоразумений настоятельно рекомендуется “формула”:

    \usetheme[numbers, totalnumbers, compress]{Statmod}

(иногда разумно использовать не compress, а minimal)

You’ve been warned :-)

## Сборка

Слайды можно компилировать двумя способами:

### Latex2Pdf

В WinEdt есть соответствующая кнопка; результат (pdf) можно смотреть с помощью Acrobat Reader.

**Особенности**:

- Не понимает формат графики eps. Понимает jpg (pdf, png).
- В documentclass должна быть опция pdf
- Нужен установленный Acrobat Reader (версия >=6)

### latex + ps2pdf

Используется связка latex, dvips, ps2pdf (смотреть, естественно, Акробатом).

**Особенности**:

- Понимает eps, не понимает jpg.
- В documentclass должна быть опция dvips
- Нужен установленный Acrobat Reader (версия >=6) и GhostScript посвежее.

При желании, можно сделать cmd-файл (файл с расширением cmd), запуск которого будет делать все необходимые операции (чтобы не нажимать на много кнопочек). Например, такой:

    latex slides.tex
    latex slides.tex
    dvips -P pdf slides.dvi
    ps2pdf14 slides.ps

P.S. Тема Statmod рассчитана на использование способа с pdflatex’ом. Способ ps2pdf может быть добавлен по “пожеланиям трудящихся”.
