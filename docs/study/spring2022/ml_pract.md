03.03 Задание на 20.03. Построение многомерных данных из временного ряда (по первым m, m<L, столбцам предсказываем (L+1)-го; L можно взять 50), разбиение на train, validation и test, примерно 700,300,300 (или 750, 250, 250).  
Построение стратегии, на основе знания того, как устроена модель ряда (но не зная значения параметров) - на основе m точек оценивание угла наклона a и прогноз x\_{n+1} = x\_{n}+a; подбор m от 2 до L перебором MSE на validation, можно с каким-то шагом.  
Результат - MSE прогноза на один шаг вперед, среднее по train, по validation и по test.  
Всю эту конструкцию заключаете в цикл, моделируя ряд, скажем, 100 раз и усредняя ошибки. Ошибка на test должна быть меньше, чем для прогноза на один шаг вперед, но больше, чем по прогнозу с инсайдерской информацией о значении a (эти прогнозы тоже реализуйте).  
Для тестирования рассмотрите ряды с шумом, без шума, только из шума, а также с и без изломов.
