## Программа курса


### Темы состоявшихся занятий


1.  Введение. Краткий обзор. Базовые операции: понятие “workspace”, присваивание, просмотр списка переменных, удаление переменных из workspace’а. Функции c() и seq(). Использование встроенной справки. // (12.02.2013, частично) //
2.  Объекты R. Общие свойства (mode, length). Основные типы объектов: vector, matrix, data frame, list, expression. Конверсия объектов друг в друга. // (12.02.2013) //
3.  Основные операции (арифметика, логические операции). Проверка равенства (==, identical, all.equal). Индексирование “векторных” переменных (включая именованные индексы). // (12.02.2012, 19.02.2013) //
4.  Вызов функций. Правила передачи аргументов. Аргументы по умолчанию. Ellipsis (…) operator. Область видимости переменных // (19.02.2013) //
5.  Чтение и запись данных из файла. Функции scan, read.table, write.table и пр. // (19.02.2013) //
6.  Основные встроенные “скалярные” функции: sum, prod, max, min, which.max, which.min, range, length // (19.02.2013) //
7.  Основные встроенные “векторные” функции: round, rev, sort, rank, scale, pmin, pmax, cum{sum, prod, min, max}, diff, match, which // (19.02.2013) //
8.  Операции с матрицами: cbind, rbind, t, diag, solve, qr, eigen, svd // (26.02.2013) //
9.  Функции над блоками данных: lapply, sapply, replicate // (26.02.2013) //
10. Графические устройства (функции dev.*). Разбиение устройства на блоки. Понятие о графических параметрах // (26.02.2013) //
11. Высокоуровневые графические функции: plot, curve, pairs, density // (26.02.2013) //
12. Низкоуровневые графические функции: points, line, axis, legend // (26.02.2013) //
13. Распределения. Функции распределения, плотности. Моделирование. Функции “d”, “p”, “q”, “r”. Функция sample // (26.02.2013) //
14. Отладка. Функции debug, browser, traceback // (05.03.2013) //
15. Векторизация. Эффективная работа с памятью // (05.03.2013) //
16. Нахождение (локальных) экстремумов функций // (05.03.2013) //
