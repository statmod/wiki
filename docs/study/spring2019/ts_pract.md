R код АЧХ (хотя наверняка есть и в каком-то пакете, но тут - в лоб)

`afc <- function(filter, omega) { k <- seq_along(filter) - 1 h <- function(o) sum(rev(filter) * exp(-k*1i * o)) abs(sapply(omega, h)) }  freq <- seq(0, pi, 0.001) filt <- rep(1, 100) filt <- c(-1,1) filt <- c(-1,2,-1) omega <- freq/2/pi plot(afc(filt, freq) ~ omega, type = “l”) `
