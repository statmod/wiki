## Программа курса

### Задачи

1.  Вычисление интеграла методом Монте-Карло *(17.02.2015)*
2.  Оценки максимального правдоподобия *(24.02.2015)*
3.  EM-алгоритм. Построение ОМП для смеси нормально распределенных случайных величин // (03.03.2015) //
4.  Support Vector Machines // (10.03.2015) //
5.  Моделирование. Адаптивный метод отбора // (17.03.2015) //
6.  Бутстреп // (24.03.2015) //

### (Возможные) будущие задачи

1.  Вычисление стационарного распределения марковской цепи
2.  Метод Гусеница-SSA
3.  Проверка статистических гипотез
4.  Кластерный анализ
5.  Нейронные сети
6.  Деревья классификации и регрессии. Методы улучшения классификаторов. Bagging. Boosting. Алгоритм AdaBoost
7.  Моделирование. Markov Chain Monte-Carlo. Метод Метрополиса-Хастингса. Метод Гиббса.
8.  Логистическая и нелинейная регрессия
9.  Планирование эксперимента
10. Hidden Markov Models
11. …
