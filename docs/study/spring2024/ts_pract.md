### Литература и ссылки

1.  Ссылка на R-пакет [Rssa](https://cran.r-project.org/web/packages/Rssa/index.html), версия R будет нужна не меньше 3.2
2.  Статьи-tutorial для Rssa:
    - Nina Golyandina, Anton Korobeynikov, Anatoly Zhigljavsky “Singular spectrum analysis with R”, 2018. Сайт с примерами в R из книги <http://ssa-with-r-book.github.io>
    - Базовый метод (примеры частично не работают с новой версией пакета v1): N.Golyandina, A.Korobeynikov. Basic Singular Spectrum Analysis and Forecasting with R. Computational Statistics and Data Analysis. Volume 71, March 2014, pp.934-954. Версия в [Arxiv](http://arxiv.org/abs/1206.6910)
3.  Многомерные обобщения метода и общая схема: N.Golyandina, A.Korobeynikov, A.Shlemov, K.Usevich. Multivariate and 2D Extensions of Singular Spectrum Analysis with the Rssa Package. Journal of Statistical Software, v.67, Issue 2, 2015, pp.1-78. Открытый доступ к статье с кодом примеров: [J.Stat.Soft.](https://www.jstatsoft.org/article/view/v067i02)
4.  (не будет использоваться в курсе) Программа [CaterpillarSSA](http://www.gistatgroup.com/gus/programs.html) (Windows). Для получения рег.ключа к студенческой версии мне нужно прислать запрос.
