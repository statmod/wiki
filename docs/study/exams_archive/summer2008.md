## Комментарии


1.  Все экзамены начинаются в 10:00, если нет специальной договоренности
2.  Дата экзамена по спецкурсу может быть перенесена по согласованию с преподавателем.
3.  Если спецкурс сдан досрочно всеми студентами специализации, то экзамен в срок не состоится (очевидно :-))
4.  Консультации по спецкурсам обычно происходят при наличии заявок со стороны студентов
