## Зачет

 Для получения зачета необходимо:

1.  Выбрать статью для верстки
2.  Представить переверстанную в LaTeX математическую статью из википедии. Должна содержать формулы, оглавление, ссылки, библиографию (до 23:59 MSK 22.11)
3.  Письмо (до 23:59 MSK 22.11)
4.  Доп. задание по библиографии (для особо отличившихся)
5.  Отчет о курсовой
6.  Слайды
7.  Сделать доклад
