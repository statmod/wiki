Обновленные ссылки от Alex Shlemov:

1.  [http://cplusplus.com/](http://cplusplus.com/) Всякая инфа по языку и документация по использованию встроенной библиотеки с примерами. Коротко и удобно.
2.  [http://en.cppreference.com/w/](http://en.cppreference.com/w/) Аналогично предыдущему ресурсу.
3.  [C++ 11 Standard latest draft](http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2012/n3376.pdf) Последний черновой вариант Чтение не очень захватывающее, документ пропитан духом формализма. Но позволяет точно ответить на вопрос “А как это должно быть на самом деле?”
4.  [C++ 14 Standard latest draft](http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2013/n3797.pdf) Последний черновой вариант стандарта C++
5.  [C++ 17 Standard latest draft](http://www.open-std.org/JTC1/SC22/WG21/docs/papers/2017/n4659.pdf) Последний черновой вариант стандарта C++
6.  [Cpp 11/14 compiler and library shootout](http://cpprocks.com/c1114-compiler-and-library-shootout/) Сводная таблица по поддержке новых возможностей различными компиляторами.
7.  [Примеры на новые возможности C++ 17](https://github.com/AnthonyCalandra/modern-cpp-features/blob/master/CPP17.md)
8.  [MSDN C++](https://docs.microsoft.com/en-us/cpp/cpp/cpp-language-reference) Позволяет ответить на вопрос “А как же оно на самом деле работает” применительно к майкрософтовской реализации C++ (Visual C++). В целом, удобная онлайн-справка по языку и Visual Studio IDE. Некоторыми признается вообще лучшей документацией по языку.
