## Зачет

Для получения зачета необходимо представить:

1.  Переверстанную в LaTeX математическую статью из википедии. Должна содержать формулы, оглавление, ссылки, библиографию
2.  Доп. задание по библиографии (для особо отличившихся)
3.  Отчет о курсовой
4.  Слайды
5.  Сделать доклад
