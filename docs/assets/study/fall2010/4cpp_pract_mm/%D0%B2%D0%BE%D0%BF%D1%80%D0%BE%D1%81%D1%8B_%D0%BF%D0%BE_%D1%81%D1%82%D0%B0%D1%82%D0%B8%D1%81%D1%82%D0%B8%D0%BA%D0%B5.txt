Приблизительный список вопросов к зачету по статистике и моделированию:

1) Два вида случайных генераторов. Их сравнение.
2) Об особенностях мультипликативного датчика (периодичность, разная периодичность разрядов, повторяемость, предсказуемость, конечное множество траекторий)
3) Метод обратных функций
4) Моделирование смеси распределений.
5) Табличный метод моделирования д.с.в. Его простейшая оптимизация --- сортировка. Трудоемкость метода.
6) Дихотомия
7) Чжень
8) Волкер
9) Преобразование Бокса-Мюллера и полярный метод моделирования нормального распределения.
10) Идея отбора. Формула для отбора в общем случае, ее графическое объяснение.
11) Задача о тасовке колоды. Справедливая тасовка.
12) Понятие о критерии. Статистика критерия, уровень значимости, доверительная/критическая области
13) p-value, распределение p-value, трактовка p-value
14) Критерий Пирсона для непрерывных и дискретных распределений. Постановка задачи, вид статистики, условия применимости.
15) О проблеме больших и малых объемов выборки. Состоятельность, мощность.
16) Различные виды критических областей на примере Мышки и Морковки (только для непрерывных критериев)
17) Различные критерии для МиМ (только непрерывные)
